# Acrobat StudioのAnalyzerの概要

Acrobat StudioのAnalyzerを使用すると、ビジネス・ユーザーは、数万個の非構造化ドキュメントから構造化された監査可能な洞察を抽出し、ドキュメント中心のビジネス・プロセスを自動化できます。

## 新機能

>[!BEGINTABS]

>[!TAB 開始する]

[構造化された引用文献に登録されたデータを大量のドキュメントから取得する方法を学びましょう](get-started.md)。

>[!TAB コレクションを使用]

手動でリンクされた[コレクション](collections.md)を作成する方法、属性を適用する方法、コンテンツの成長に合わせてドキュメントを整理する方法について説明します。

>[!ENDTABS]

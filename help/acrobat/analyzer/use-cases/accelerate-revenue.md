# 財務における収益と監査のレビューの迅速化

収益に関する重要な情報は、数百に及ぶ契約に分散していることが多いため、監査や財務決算の前に会計リスクを特定することは困難です。 Acrobat StudioのAnalyzerを使用して、財務チームが大規模な契約データを抽出、確認、検証し、監査の準備、収益認識、リースのコンプライアンスを向上させる方法について説明します。

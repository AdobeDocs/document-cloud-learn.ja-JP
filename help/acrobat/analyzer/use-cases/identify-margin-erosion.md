# 侵食マージンのソース検出の識別のための下請管理

プロジェクトのマージンは、プライムコントラクトレベルでは失われません。 契約は一度に1つずつ失われます。つまり、リカバリの価格設定が決まる前から拡大していた変更管理、遅れ請求へと静かに移行するRFI、および保険料紙に掲載されることのない契約保護です。 それが報告書に出るころには、そのお金はもう無くなっていた。 プロジェクトの収益性に影響を与える前に、未実施の変更管理、経年劣化した情報依頼、および契約のギャップを明らかにすることで、下請契約における隠れたマージン浸食のリスクを特定する方法について説明します。

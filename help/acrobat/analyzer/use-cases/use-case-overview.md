# Acrobat StudioのAnalyzerの使用例の概要

Acrobat StudioのAnalyzerを使用して、チームが大量の文書のコレクションから貴重な情報を抽出する方法について説明します。 レビュープロセスを合理化し、洞察を明らかにし、文書のコンテンツを即戦力となるデータに変換する方法を示す、実際のユースケースを探ります。

## 新機能

>[!BEGINTABS]

>[!TAB 仕入先契約のリスクの特定]

Acrobat Studioのアナライザーを使用して、[ベンダー契約による情報セキュリティのリスク](vendor-risk.md)をプロアクティブに特定する方法について説明します。

>[!TAB 侵食マージンの特定]

Acrobat Studioのアナライザーを使用して、[下請業者契約全体のマージン損失](identify-margin-erosion.md)の早期警告サインを検出し、コストが上昇する前に対処する方法について説明します。

>[!TAB 収益と監査レビューの促進]

Acrobat Studioのアナライザーを使用して、[財務](accelerate-revenue.md)チームが大規模に契約データを抽出、レビュー、検証する方法について説明します。

>[!TAB データプライバシーのリスク分析]

Acrobat StudioのAnalyzerを使用して、[プライバシー、法務、調達チーム](data-privacy-risk.md)が重要なDPA条件を大規模に抽出、監視、検証する方法について説明します。

>[!ENDTABS]

# Acrobat StudioのAnalyzerの使用例の概要

Acrobat StudioのAnalyzerを使用して、チームが大量の文書のコレクションから貴重な情報を抽出する方法について説明します。 レビュープロセスを合理化し、洞察を明らかにし、文書のコンテンツを即戦力となるデータに変換する方法を示す、実際のユースケースを探ります。

## 新機能

>[!BEGINTABS]

>[!TAB 財務における収益と監査のレビューの促進]

Acrobat Studioのアナライザーを使用して、[財務](accelerate-revenue.md)チームが大規模に契約データを抽出、レビュー、検証する方法について説明します。

>[!TAB データプライバシーのリスクを完全に可視化して監視する]

Acrobat StudioのAnalyzerを使用して、[プライバシー](data-privacy-risk.md)が、法務部門および調達部門の重要なDPA条件を大規模に抽出、監視、検証する方法について説明します。

>[!ENDTABS]

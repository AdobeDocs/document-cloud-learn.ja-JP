# 送信前に文書とテンプレートを編集

直前の変更は、すべてのワークフローの一部です。 このチュートリアルでは、Acrobat Signで文書の内容の更新、画像の置き換え、テンプレートの修正を直接行う方法について説明します。

機能の詳細と制限の詳細は、[こちら](https://helpx.adobe.com/sign/web/authoring/edit-agreement/new.html)でご確認いただけます。

>[!NOTE]
>
>ドキュメントの編集は管理者が有効にする必要があります。詳細については、[こちら](https://helpx.adobe.com/sign/web/settings-configuration/send-settings/edit-agreement.html)を参照してください。
